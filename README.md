# 집 (ChanHome)

Smart eLife(대림 e편한세상) 아파트 스마트홈을 서버 없이 iPhone 혼자 제어하는 앱.

- iPhone이 `smartelife.apt.co.kr`에 직접 HTTPS 요청 (원본 파이썬 클라이언트와 같은 요청 형식)
- 기본 방: 방 3 (침실3) — 조명, 에어컨, 난방, 콘센트
- 일정: 정해진 시각에 조명/에어컨/난방/콘센트 켜기·끄기 (백그라운드 무음 오디오 + 실행 실패 시 알림의 [지금 실행])
- 계정 정보는 기기 키체인에만 저장. 이 저장소에는 개인 정보가 없음

`-demo` 실행 인수로 네트워크 없이 데모 데이터를 보여준다 (CI 스크린샷용).
